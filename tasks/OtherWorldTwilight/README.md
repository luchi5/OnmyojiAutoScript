# 彼世逢魔

任务与识别素材以 [runhey 的实现](https://github.com/runhey/OnmyojiAutoScript/tree/c496ea55fe77a39e70d19dcc4e3032931607abad/tasks/OtherWorldTwilight) 为基础，保留原作者署名，按本分支的战斗、邀请与御魂接口适配，遵循项目根目录 GPLv3 许可证。

支持单人、队长和队员，任务默认关闭；可设置次数和时长上限，默认 30 次、30 分钟，先达到任一限制即结束。次数按进入战斗统计，并不表示每场都获胜。

支持锁定阵容、好友邀请、按编号或名称切换御魂。彼世逢魔站位会变化，绿标按式神名称识别；请填写目标名称，最多查找 6 秒，未找到就不点击。普通副本的位置绿标保持原逻辑。

任务位于“御魂副本”。已有后台需要在正常退出后重新打开，才能载入新的任务模型和菜单；更新源码不会强制重载运行中的账号。

离线回归见 `tests/test_other_world_twilight.py`，只执行真实方法的 AST、纯配置模型及模拟画面，不连接设备、后端或 OCR 服务。
