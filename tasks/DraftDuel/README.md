# 协同对弈

双账号设置为一位队长、一位队员，并相互填写脚本配置名和游戏昵称。
双方启动协同对弈任务，队长负责两端操作。队长的 `challenge_limit` 是完整轮数：
达到6胜或2败、完成双方整轮结算及返回后才计1轮，不按单场计数。

流程包含组队、选将、阵容选择、匹配、上阵、自动战斗、单场结果和整轮结算。
匹配超时、掉线、漏点击、识别暂时失败和双方进度不同步会自动重试或重新识别。
按配置完成所有轮后双方退出任务。旧 `coin_budget` 和 `free_only` 字段不再限制开轮。

`log/draft-duel-series/<pair_id>/batch.json` 保存已结算轮数；各轮独立保存断点和头像。
恢复时不重复计数，不重开已经完成的轮。单轮达到时间上限会保存进度，供下次任务调用恢复。

离线测试覆盖多轮计数、断点、队员同步及恢复；这不代表完整轮已经实机验收。
公开仓库仅包含代码、模拟测试和不含账号资料的界面裁剪素材，不包含账号配置、日志和原始截图。
公开版本沿用项目现有本地OCR后端。

运行模拟回归：

```powershell
python -B -m unittest discover -s tests -p 'test_draft_duel_*.py' -q
```
